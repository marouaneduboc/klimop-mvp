# Visual asset attribution — Lichte Klimop

Free / open-licensed icons only. No paid assets. No homemade Klimmie ivy. No AI-generated characters.

- Source: https://github.com/microsoft/fluentui-emoji
- Asset: Flat style `Lion` (`assets/Lion/Flat/lion_flat.svg`, Unicode 🦁 / U+1F981)
- Vendored SVG: `icons/lion.svg`
- License file: `icons/FLUENT-EMOJI-LICENSE.txt`
- Used as the cute Dutch-lion logo/mascot (Home hero, onboarding, celebrate, brand mark). Path geometry is inlined in `illustrations.tsx` (`LionFace`) to match the vendored SVG.

## Lichte Klimop original geometric motifs (CC0)
- `icons/tulip.svg`, `icons/windmill.svg`, `icons/canal.svg`
- Simple flat geometric Dutch marks (tulip, molen/windmill, canal) drawn for this project.
- Soft-fill compositions in `illustrations.tsx` (heroes, empty/grammar scenes) reuse these shapes alongside the lion mascot.
- Dedicated to the public domain (CC0 1.0).

## Intentionally not used
- Homemade Klimmie ivy / custom animal characters.
- Confetti spam or over-the-top bobbing animations.
- Paid stock, proprietary icon kits, or AI-generated characters.
