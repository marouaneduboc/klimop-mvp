# Local TLS certs (gitignored `*.pem`)

Generated by `./run-local.sh` via **mkcert** (preferred) for:

- `localhost`, `127.0.0.1`, `::1`
- current LAN IP (so the phone can open `https://LAN-IP:5175`)

Do not commit `*.pem`. Re-run `./run-local.sh` after Wi‑Fi / IP changes to refresh the cert SAN list.
